# Editorial Taste & Curation Guidelines

This policy file is authored and owned by the human operator. The evaluation agent reads this file during every run but has **no authority to modify it**.

---

## 1. High-Signal Inclusion Criteria (Target: 3 to 5 top items)
- **Empirical Hardware Benchmarks:** Real measurements of token throughput, TTFT, memory bandwidth, or VRAM offloading.
- **Architectural Breakdowns:** In-depth analysis of hybrid linear attention, MoE routing efficiency, or speculative decoding.
- **Post-Mortem Engineering:** Candid writing detailing failure modes, debugging production outages, or performance bugs.
- **Agent System Design:** Real-world workflows showing loops, MCP tooling, or multi-agent orchestration.

---

## 2. Hard Disqualification Filters (Skip Immediately)
- Generic top-10 tool listicles or promotional SEO roundups.
- Speculative cryptocurrency, venture capital hype, or corporate marketing PR.
- Vague high-level announcements without technical implementation details or code.
- Articles behind heavy paywalls or requiring login.
